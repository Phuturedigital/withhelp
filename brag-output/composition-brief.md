# Hyperframes Composition Brief: WITH.

## Objective
Create a short launch-style brag video for the WITH. public website and concept.

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Format: landscape — 1280x720
- Duration: 21 seconds

## Source Material
- Project: `Phuturedigital/withhelp`
- Primary sources: `api/site.ts`, `docs/BRAND-GUIDE.md`, `docs/WITHHELP.md`, `shared/with-brand-contract.json`
- Product name: WITH.
- Strongest claim: “Safety should start before the emergency.”
- Key UI moment: the website hero and the Guardian / Private Risk / Assistance Point product story.
- Copy that must appear verbatim:
  - “Safety should start before the emergency.”
  - “Not another panic button.”
  - “One failure should not end the chain.”
  - “Guardian”
  - “Private Risk”
  - “Assistance Points”

## Creative Direction
- Tone preset: polished
- Creative direction: quiet premium public-safety concept film
- Interpretation: serious and elegant, with generous spacing and calm reveals. Avoid fear marketing.
- Angle: WITH. connects fragmented safety layers into one continuity system that begins before crisis.
- Hook: “Safety should start before the emergency.”
- Outro: WITH. + tagline + `withhelp.co.za`
- Avoid:
  - generic SaaS language
  - crime imagery
  - fake coverage
  - fake response times
  - fake partner logos
  - fake safety scores
  - alarm/siren aesthetics

## Visual Identity
- Background: #F5F2EA
- Text: #111417
- Accent: #FF6248
- Protected state: #C8F678
- Display font: Inter
- Body font: Inter
- Visual references: editorial typography, rounded browser/product surfaces, restrained system diagrams

## Storyboard
1. Brand promise — 4s — tagline on cream.
2. Website reveal — 5s — recreated website hero.
3. Product pillars — 5s — Guardian, Private Risk, Assistance Points.
4. Continuity principle — 4s — network survives one failed connection.
5. Outro — 3s — WITH. / tagline / withhelp.co.za.

## Audio
- Audio role: sparse professional support
- Audio arc: warm ambient bed, subtle lift through scenes 2–4, fade under logo
- Music: locally generated ambient bed for this environment
- SFX: soft transition chimes only
- Restraint: no emergency sounds and no dramatic threat cues

## Truth / prototype boundary
This is a concept and research-stage brand film.
Do not imply that:
- Assistance Points are already operational nationwide
- professional response coverage is currently active
- the app provides guaranteed protection
- map/coverage examples are live
